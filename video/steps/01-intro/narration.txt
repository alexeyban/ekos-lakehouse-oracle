This is a recording of one real run, start to finish. The source is eye dempiere, an open source E R P on Oracle, with nine hundred tables, twenty years of migration scripts and a large Java code base. We create a new project in the Ekos console and take it through the seven steps of the operator workflow. Analyse the sources. Generate the documentation. Review and sign off the source model. Describe the reports we want. Approve how each table is loaded. Build bronze and silver. And build the gold marts, each one reconciled against silver. Nothing here is staged: every screen is from this run, and every number we say is on screen. Where something went wrong during the recording, we say so, and we show how it was fixed.
